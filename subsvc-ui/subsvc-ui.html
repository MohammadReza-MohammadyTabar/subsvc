💡 راهنمای v2rayNG
  1. اپ v2rayNG رو باز کن
  2. از منوی بالا → Subscription → Add
  3. URL بالا رو پیست کن
  4. روی subscription ذخیره‌شده لمس کن → Update
  5. تمام کانفیگ‌های سالم اضافه می‌شن
⚠️ نکات امنیتی

این URL از سمت کلاینت توکن نمی‌خواد (اپ‌ها نمی‌تونن هدر بفرستن)؛ UI با توکن سرور (SUBSVC_AUTH_TOKEN) از طرف شما درخواست می‌کنه. بقیه‌ی API (تنظیمات، لینک‌ها، حذف) بدون توکن شما از طریق UI قابل دسترسی نیست. هر کسی که به پورت 9090 دسترسی داشته باشه می‌تونه لیست کانفیگ‌ها رو ببینه. اگه این برات مهمه، پورت 9090 رو توی فایروال محدود به IP خودت کن.

⚙️ تنظیمات عملیاتی

بدون تغییر
این تنظیمات در سرور ذخیره می‌شن (settings.json در data_dir) و بعد از restart هم می‌مونن. تغییرات از کار بعدی اعمال می‌شن؛ کار در حال اجرا با تنظیمات قبلی تموم می‌شه. معیار موفقیت و رتبه‌بندی فوراً روی «خروجی» و «کانفیگ‌ها» اثر می‌ذارن، بدون تست مجدد.

🔒 تنظیمات استقرار (فقط‌خواندنی)

از متغیرهای محیطی SUBSVC_* خوانده می‌شن و در زمان اجرا قابل تغییر نیستن؛ برای تغییر، env یا docker-compose را عوض کنید و سرویس را restart کنید.

🧹 پاک‌سازی گروهی

این عملیات برگشت‌ناپذیره. فقط کانفیگ‌هایی که مطمئنی دیگه لازم نداری رو حذف کن.

❌ حذف کانفیگ‌های ناموفق

کانفیگ‌هایی که تست شدن ولی معیارهای موفقیت (تنظیمات) را برآورده نمی‌کنند (timeout، YouTube، سرعت، ...).

⏳ حذف کانفیگ‌های تست‌نشده

کانفیگ‌هایی که هنوز تست نشدن (و پشتیبانی‌شده هستن).

🚫 حذف کانفیگ‌های پشتیبانی‌نشده

کانفیگ‌هایی که Xray-core نمی‌تونه اجراشون کنه (hysteria2، tuic، ssr، anytls، ...).

🔴 حذف همه‌ی unreachable‌ها (ناموفق + تست‌نشده + پشتیبانی‌نشده)

هر چیزی که در خروجی نیست. خطرناک‌ترین گزینه — فقط کانفیگ‌های واجد شرایط می‌مونن.

💥 حذف کامل همه‌ی کانفیگ‌ها (پاک کردن کل لیست)

هشدار: همه‌ی کانفیگ‌ها پاک می‌شن، چه سالم چه خراب. لینک‌های اشتراک باقی می‌مونن و با refresh بعدی دوباره پر می‌شن.
